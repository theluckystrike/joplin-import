# Joplin Export Import demo

This folder has two JEX files from the same demo notebook set:

- `Joplin export.jex`: 3 notebooks, 5 notes, 2 tags and 2 resources. One note is an HTML web clip and one resource has no file.
- `Joplin export later.jex`: the same archive after two notes changed. Use it with the Pro resync.

Run the command "Joplin Export Import: Import a Joplin archive".
